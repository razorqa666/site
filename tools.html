Инструменты для работы
с микроразметкой

Валидаторы, генераторы, плагины и расширения браузера для удобной работы со структурированными данными.

Валидаторы от Google

🔍
Rich Results Test
Официальный инструмент Google для проверки поддержки rich results. Показывает предпросмотр сниппета. search.google.com/test/rich-results
📊
Search Console
Отчёт «Расширенные результаты» показывает ошибки и предупреждения разметки для проиндексированных страниц.
🗺
Schema Markup Validator
Инструмент от schema.org для проверки любой разметки (включая типы вне Rich Results). validator.schema.org

Расширения для Chrome

  • Structured Data Testing Tool — видит всю разметку на текущей вкладке в один клик
  • SEO Meta in 1 CLICK — показывает мета-теги и разметку страницы
  • JSON-LD Viewer — подсвечивает и форматирует JSON-LD на странице
  • Schema Builder — генерирует код разметки прямо в браузере
  • OpenLink Structured Data Sniffer — определяет все форматы разметки на странице

Пошаговый процесс внедрения

  1. Определите типы страниц вашего сайта (статьи, товары, рецепты и т.д.)
  2. Выберите подходящие типы Schema.org для каждого шаблона страницы
  3. Составьте JSON-LD разметку вручную или с помощью генератора
  4. Проверьте разметку в Rich Results Test до публикации
  5. Внедрите разметку на сайт (вручную, через плагин CMS или GTM)
  6. Запросите переобход страниц в Google Search Console
  7. Мониторьте отчёт «Расширенные результаты» в Search Console
  8. Исправьте ошибки и предупреждения по мере их появления

Добавление через Google Tag Manager

GTM позволяет внедрить JSON-LD без изменения кода сайта — удобно для маркетологов и SEO-специалистов без доступа к исходникам:

/* Тег GTM: Custom HTML */
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "{{Site Name}}",  /* переменная GTM */
  "url": "{{Page URL}}"
}
</script>

/* Триггер: All Pages (или конкретные шаблоны) */
Совет: При использовании GTM убедитесь, что скрипты рендерятся до индексации. Google умеет исполнять JavaScript, но задержка рендеринга может влиять на своевременную индексацию разметки.
