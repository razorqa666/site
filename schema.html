Schema.org — словарь типов

Совместный проект Google, Microsoft, Yahoo и Yandex — единый словарь семантических типов и свойств.

Что такое Schema.org

Schema.org — это открытый словарь (онтология) понятий и их свойств, запущенный 2 июня 2011 года. Он определяет несколько сотен «типов» (Thing, Person, Product, Event…) и тысячи «свойств» для описания реального мира в машиночитаемом виде.

Проект управляется сообществом через GitHub-репозиторий и регулярно обновляется. Актуальная версия словаря доступна на schema.org.

Версия на 2026 год: Schema.org содержит более 800 типов и свыше 1400 свойств, охватывающих медицину, финансы, спорт, науку, образование и другие области.

Иерархия типов

Все типы Schema.org наследуются от базового класса Thing. Иерархия похожа на ООП: дочерние типы наследуют все свойства родительских и добавляют собственные.

Thing
├── Action
├── CreativeWork
│   ├── Article
│   │   ├── NewsArticle
│   │   └── BlogPosting
│   ├── Book
│   ├── Movie
│   └── Recipe
├── Event
├── Intangible
│   ├── JobPosting
│   └── Rating
├── Organization
│   └── LocalBusiness
│       └── Restaurant
└── Person

Свойства и значения

Каждый тип имеет набор допустимых свойств. Свойства могут принимать значения примитивных типов (Text, Number, Date, URL, Boolean) или ссылаться на другие типы Schema.org.

{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Кофейня «Код»",            // Text
  "telephone": "+7-495-000-00-00",   // Text
  "url": "https://example.ru",          // URL
  "priceRange": "₽₽",                 // Text
  "address": {                       // PostalAddress
    "@type": "PostalAddress",
    "streetAddress": "ул. Тверская, 1",
    "addressLocality": "Москва",
    "addressCountry": "RU"
  }
}

Расширения Schema.org

  • schema:auto — расширение для автомобильной отрасли
  • schema:bib — библиографические данные, книги, статьи
  • schema:health-lifesci — медицина и науки о жизни
  • schema:meta — метаданные для самого словаря
  • schema:pending — типы, ожидающие официального утверждения
