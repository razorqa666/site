Микроразметка
Schema.org и JSON-LD

Практическое руководство по семантической разметке данных для поисковых систем и обогащённых сниппетов.

Что такое микроразметка?

Микроразметка — это стандартизированный способ аннотировать HTML-документ структурированными данными, понятными поисковым системам, краулерам и другим автоматизированным агентам. Вместо того чтобы работать только с текстом страницы, поисковый робот может точно «понять»: перед ним рецепт с рейтингом 4.8, статья, написанная конкретным автором, или событие с датой и местом проведения.

Разметка не отображается пользователю на странице — она существует как слой метаданных поверх обычного HTML и служит мостом между контентом сайта и машиночитаемым описанием этого контента.

Быстрый пример JSON-LD

Вот минимальная разметка статьи, которую рекомендует Google:

index.html — тег <script> в <head>
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Что такое микроразметка",
  "author": {
    "@type": "Person",
    "name": "Жуковский Даниил"
  },
  "datePublished": "2026-09-01"
}
</script>
Совет: JSON-LD вставляется в <head> или в конец <body> и не требует изменений в видимой HTML-разметке.

Три формата разметки

Формат Где размещается Поддержка Google Сложность
JSON-LD Отдельный <script> ✓ Рекомендуется Низкая
Microdata Атрибуты HTML-тегов ✓ Поддерживается Средняя
RDFa Атрибуты HTML-тегов ✓ Поддерживается Высокая
