Что такое микроразметка

История появления, принципы работы и зачем она нужна веб-разработчику.

История и предпосылки

Семантическая веб-разметка берёт начало с концепции «Семантической паутины», предложенной Тимом Бернерсом-Ли в 2001 году. Идея состояла в том, чтобы данные в интернете были не просто текстом для людей, но и машиночитаемыми структурами, которые программы могут понимать и обрабатывать автоматически.

Первые шаги к структурированным данным были сделаны через форматы Dublin Core (1995) и RDF (1999). Однако широкое практическое применение получила микроразметка после запуска проекта Schema.org в 2011 году — совместной инициативы Google, Microsoft (Bing), Yahoo и Yandex.

  1. 1995 — Dublin Core: первый стандарт метаданных для веб-документов
  2. 1999 — RDF: рамочная модель Resource Description Framework от W3C
  3. 2004 — Microformats: упрощённый подход с классами CSS
  4. 2008 — RDFa: встраивание RDF прямо в HTML-атрибуты
  5. 2009 — Microdata: часть HTML5-спецификации
  6. 2011 — Schema.org: единый словарь от крупнейших поисковиков
  7. 2014 — JSON-LD 1.0: стал рекомендацией W3C, Google начал активно продвигать

Как это работает

Поисковый робот при обходе страницы читает обычный HTML. Но текст «Оценка: 4.8 из 5» он воспринимает просто как набор символов. С микроразметкой тот же контент становится структурированным:

/* Без микроразметки — просто текст */
Оценка: 4.8 из 5, 120 отзывов

/* С JSON-LD — машиночитаемые данные */
"aggregateRating": {
  "@type": "AggregateRating",
  "ratingValue": "4.8",
  "ratingCount": "120",
  "bestRating": "5"
}

Получив структурированные данные, Google может отображать звёзды рейтинга прямо в результатах поиска (rich snippets), добавлять информацию в Google Knowledge Graph, использовать данные для голосового поиска и Google Assistant.

Кто использует микроразметку

  • Интернет-магазины — товары, цены, наличие, отзывы покупателей
  • Рецептурные сайты — ингредиенты, время приготовления, калории
  • СМИ и блоги — статьи, авторы, дата публикации
  • Афиши и события — концерты, конференции, дата, место, цена билетов
  • Компании и организации — адрес, телефон, часы работы, соцсети
  • Образовательные платформы — курсы, преподаватели, продолжительность
  • Сервисы вакансий — должность, зарплата, тип занятости, работодатель

Принцип разделения слоёв

Важно: Микроразметка существует отдельно от визуального представления страницы. Вы можете добавить или изменить разметку без изменения того, что видит пользователь. Это ключевое отличие от мета-тегов: разметка описывает смысл контента, а не просто его метаинформацию.
Предупреждение: Google требует, чтобы размеченный контент реально отображался на странице для пользователей. Разметка скрытого контента является нарушением Руководства Google и может привести к ручным санкциям.
