Основные типы Schema.org

Справочник по наиболее часто используемым типам и их свойствам.

Article / NewsArticle / BlogPosting

Тип для статей, новостей и публикаций в блоге. Поддерживается в Google News и Article Rich Results.

СвойствоТип значенияОбязательное?Описание
headlineTextДаЗаголовок статьи (макс. 110 символов)
imageURL или ImageObjectДаИзображение статьи (min 1200×630 px)
datePublishedDateTime (ISO 8601)ДаДата первой публикации
dateModifiedDateTime (ISO 8601)ЖелательноДата последнего изменения
authorPerson или OrganizationДаАвтор статьи
publisherOrganizationЖелательноИздатель с именем и логотипом

Product + Offer

Разметка товаров для интернет-магазинов. Обеспечивает вывод цены, доступности и рейтинга в Google Shopping и поисковой выдаче.

{
  "@type": "Product",
  "name": "Механическая клавиатура Keychron K2",
  "brand": { "@type": "Brand", "name": "Keychron" },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.7", "reviewCount": "834"
  },
  "offers": {
    "@type": "Offer",
    "price": "8990",
    "priceCurrency": "RUB",
    "availability": "https://schema.org/InStock"
  }
}

FAQPage

Разметка страниц с вопросами и ответами. Позволяет вопросам появляться прямо в выдаче Google в виде раскрывающегося списка.

{
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Что такое Schema.org?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Schema.org — открытый словарь типов данных..."
      }
    }
  ]
}

BreadcrumbList

Разметка хлебных крошек. Google отображает навигационную цепочку прямо в URL сниппета вместо длинного адреса.

{
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": 1,
      "name": "Главная", "item": "https://example.com/" },
    { "@type": "ListItem", "position": 2,
      "name": "Блог", "item": "https://example.com/blog/" },
    { "@type": "ListItem", "position": 3,
      "name": "Микроразметка" }
  ]
}

Event

Разметка мероприятий. Google показывает карточку события с датой, местом и ссылкой на билеты в Google Events.

СвойствоТипОписание
nameTextНазвание мероприятия
startDateDateTimeДата и время начала
endDateDateTimeДата и время окончания
locationPlaceМесто проведения
eventStatusEventStatusTypeСтатус (отменено, отложено и др.)
eventAttendanceModeEventAttendanceModeEnumerationОфлайн / онлайн / смешанный
offersOfferЦена и ссылка на покупку билетов
