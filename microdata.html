Microdata и RDFa

Форматы атрибутной разметки — встраивание семантики прямо в HTML-теги.

Microdata

Microdata — это механизм встраивания структурированных данных непосредственно в HTML, разработанный в рамках спецификации HTML5. Он использует три основных атрибута: itemscope, itemtype и itemprop.

Пример разметки Person через Microdata
<div itemscope itemtype="https://schema.org/Person">
  <h2 itemprop="name">Жуковский Даниил</h2>
  <span itemprop="jobTitle">Веб-разработчик</span>
  <a href="mailto:d@example.ru"
     itemprop="email">d@example.ru</a>
</div>

Атрибут itemscope говорит, что этот элемент описывает сущность. itemtype указывает её тип через URL Schema.org. Каждый дочерний элемент с itemprop добавляет свойство этой сущности.

RDFa

RDFa (Resource Description Framework in Attributes) — это способ встраивания RDF-данных в HTML через специальные атрибуты. Более мощный и гибкий, чем Microdata, но значительно сложнее в освоении.

Пример RDFa 1.1 Lite
<div vocab="https://schema.org/"
     typeof="Person">
  <h2 property="name">Жуковский Даниил</h2>
  <span property="jobTitle">Веб-разработчик</span>
  <a href="mailto:d@example.ru"
     property="email">d@example.ru</a>
</div>

Когда всё же использовать Microdata

Исторический контекст: До 2015 года Google активно продвигал Microdata. Многие CMS (WordPress, Drupal) имеют плагины с Microdata-разметкой. Если вы дорабатываете существующий проект с Microdata — нет смысла полностью переписывать на JSON-LD, пока разметка корректна.
  • Легаси-проекты, где уже применяется Microdata
  • Когда нельзя добавить <script>-теги в <head> (жёсткие CSP-политики)
  • Разметка, тесно связанная с конкретными DOM-элементами
