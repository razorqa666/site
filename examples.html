Примеры кода

Готовые шаблоны JSON-LD для наиболее распространённых сценариев — копируй и адаптируй.

Рецепт (Recipe)

Полная разметка рецепта
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Recipe",
  "name": "Паста карбонара",
  "author": { "@type": "Person", "name": "Шеф Антон" },
  "datePublished": "2026-01-15",
  "prepTime": "PT10M",
  "cookTime": "PT20M",
  "recipeYield": "2 порции",
  "recipeCategory": "Паста",
  "recipeCuisine": "Итальянская",
  "nutrition": {
    "@type": "NutritionInformation",
    "calories": "560 ккал"
  },
  "recipeIngredient": [
    "200 г спагетти",
    "100 г панчетты",
    "2 яйца",
    "50 г пармезана"
  ],
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.9",
    "reviewCount": "312"
  }
}
</script>

Организация (Organization)

  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "ООО «Технологии»",
  "url": "https://tech.example.ru",
  "logo": "https://tech.example.ru/logo.svg",
  "description": "Разработка веб-приложений с 2015 года",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "ул. Ленина, 42",
    "addressLocality": "Москва",
    "postalCode": "101000",
    "addressCountry": "RU"
  },
  "contactPoint": {
    "@type": "ContactPoint",
    "telephone": "+7-800-000-00-00",
    "contactType": "customer service"
  },
  "sameAs": [
    "https://vk.com/techexample",
    "https://t.me/techexample"
  ]
}

Вакансия (JobPosting)

{
  "@context": "https://schema.org",
  "@type": "JobPosting",
  "title": "Frontend-разработчик",
  "description": "Разработка интерфейсов на React...",
  "datePosted": "2026-09-01",
  "validThrough": "2026-10-01",
  "employmentType": "FULL_TIME",
  "hiringOrganization": {
    "@type": "Organization",
    "name": "ООО «Технологии»"
  },
  "jobLocation": {
    "@type": "Place",
    "address": {
      "@type": "PostalAddress",
      "addressLocality": "Москва",
      "addressCountry": "RU"
    }
  },
  "baseSalary": {
    "@type": "MonetaryAmount",
    "currency": "RUB",
    "value": {
      "@type": "QuantitativeValue",
      "minValue": 150000,
      "maxValue": 250000,
      "unitText": "MONTH"
    }
  }
}

SiteLinks Searchbox

Добавляет поисковую строку прямо в сниппет вашего сайта в брендовых запросах Google.

{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "url": "https://example.com/",
  "potentialAction": {
    "@type": "SearchAction",
    "target": {
      "@type": "EntryPoint",
      "urlTemplate": "https://example.com/search?q={search_term_string}"
    },
    "query-input": "required name=search_term_string"
  }
}
Примечание: Google самостоятельно решает, показывать ли Sitelinks Searchbox. Разметка лишь даёт подсказку о наличии поиска на сайте.
